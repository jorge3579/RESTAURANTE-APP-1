# Funcionalidades

Incluye ingreso/salida, cambio de contraseña, dashboard, CRUD y baja lógica de productos, categorías y proveedores, imágenes de producto, usuarios activables, ventas con carrito, validación de stock, entradas/salidas/ajustes, historial, auditoría, búsquedas, alertas de stock bajo y exportación PDF/Excel.

El comprobante PDF es interno y no representa una factura fiscal. No existe conexión con ARCA/AFIP.
