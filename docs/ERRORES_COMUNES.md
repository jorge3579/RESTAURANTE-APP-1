# Errores Comunes

## Error de conexión SQL Server

Verificar:

- SQL Server iniciado.
- Puerto 1433 habilitado.
- Usuario y contraseña correctos.
- TCP/IP habilitado.
- Firewall permitido.

## Error Expo Go incompatible

Actualizar Expo Go desde Play Store.
