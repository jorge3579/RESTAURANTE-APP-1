# Requisitos No Funcionales

RNF01 - El sistema debe utilizar autenticación segura mediante JWT.

RNF02 - Las contraseñas deben almacenarse cifradas mediante bcrypt.

RNF03 - El backend debe responder mediante API REST.

RNF04 - La base de datos debe ser relacional.

RNF05 - Las aplicaciones deben funcionar en Android.

RNF06 - El sistema debe registrar auditoría de acciones importantes.

RNF07 - El sistema debe permitir comunicación en tiempo real con Socket.IO.

RNF08 - El sistema debe permitir despliegue mediante Docker.

RNF09 - El sistema debe ser modular.

RNF10 - El sistema debe ser escalable para futuras versiones.
