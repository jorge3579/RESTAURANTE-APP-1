# Entrega Académica

## Nombre del proyecto

SmartRestaurantQR

## Tipo de sistema

Sistema móvil y backend para gestión integral de restaurante.

## Tecnologías

- Node.js
- Express
- SQL Server
- React Native
- Expo
- Socket.IO
- Mercado Pago

## Objetivo

Permitir reservas con pago, generación de QR, gestión de pedidos, cocina, caja, promociones y fidelización.

## Componentes

- Backend API REST
- App Cliente
- App Restaurante
- Base de datos
- Documentación
- Scripts de despliegue
