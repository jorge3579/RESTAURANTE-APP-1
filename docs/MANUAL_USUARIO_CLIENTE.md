# Manual de Usuario - Aplicación Cliente

## Introducción

SmartRestaurantQR permite realizar reservas, pedidos, pagos y acceder al restaurante mediante un código QR.

---

## Inicio de sesión

El cliente puede:

- Registrarse.
- Recuperar su acceso.
- Iniciar sesión.

---

## Menú principal

La aplicación posee los siguientes módulos:

- Inicio
- Reservas
- Menú
- Pedidos
- Beneficios
- Notificaciones
- Perfil

---

## Reservas

El usuario puede:

- Crear una reserva.
- Consultar reservas.
- Cancelar reservas.
- Ver el QR de ingreso.

---

## Pedidos

Permite:

- Elegir productos.
- Confirmar pedido.
- Pagar.
- Consultar estado.

---

## Beneficios

Incluye:

- Créditos.
- Promociones.
- Fidelización.
- Nivel VIP.

---

## Perfil

Permite:

- Consultar datos.
- Cerrar sesión.
