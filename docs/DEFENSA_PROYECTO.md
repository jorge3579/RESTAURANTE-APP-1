# Guía para la Defensa del Proyecto

## Introducción

SmartRestaurantQR es un sistema integral desarrollado como proyecto final de la Tecnicatura en Programación.

El objetivo principal es digitalizar completamente la gestión de un restaurante mediante aplicaciones móviles y un backend centralizado.

---

## Problemática

Los restaurantes suelen trabajar con:

- Reservas manuales.
- Control de mesas en papel.
- Pedidos por mozos.
- Falta de integración entre cocina y caja.
- Errores humanos.
- Mala experiencia del cliente.

---

## Solución

SmartRestaurantQR integra:

- Aplicación Cliente.
- Aplicación Restaurante.
- API REST.
- Base de datos SQL Server.

Todo sincronizado en tiempo real.
