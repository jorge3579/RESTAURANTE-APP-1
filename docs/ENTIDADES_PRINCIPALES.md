# Entidades Principales

## Usuario

Representa clientes, administradores y empleados.

## Rol

Define el perfil del usuario.

## Permiso

Controla las acciones disponibles.

## Sucursal

Representa cada local físico del restaurante.

## Mesa

Representa las mesas disponibles para reservas.

## Reserva

Representa la reserva realizada por el cliente.

## Pedido

Representa la compra realizada.

## Producto

Representa un plato o bebida.

## Pago

Representa el pago asociado a un pedido.

## QR

Representa el código de ingreso.

## Comanda

Representa la orden enviada a cocina.

## Caja

Representa apertura y cierre de caja.

## Promoción

Representa descuentos o beneficios.

## Crédito

Representa saldo a favor del usuario.

## Fidelización

Representa puntos, compras y nivel VIP.
