# Flujo de Reserva

1. Cliente inicia sesión.
2. Selecciona sucursal.
3. Indica fecha.
4. Indica hora.
5. Indica cantidad de personas.
6. El backend busca mesa disponible.
7. Se crea la reserva en estado PENDIENTE.
8. El cliente genera pedido.
9. El cliente paga.
10. Mercado Pago confirma.
11. Backend confirma la reserva.
12. Backend genera QR.
13. Cliente presenta QR.
14. Restaurante valida ingreso.
15. Mesa queda ocupada.
