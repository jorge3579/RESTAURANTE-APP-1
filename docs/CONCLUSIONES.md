# Conclusiones

SmartRestaurantQR demuestra la integración de múltiples tecnologías modernas para resolver un problema real.

Durante el desarrollo se aplicaron conceptos de:

- Arquitectura en capas.
- APIs REST.
- Autenticación JWT.
- SQL Server.
- React Native.
- Comunicación en tiempo real.
- Docker.
- GitHub.
- CI/CD.

El sistema fue diseñado para ser escalable y permitir futuras mejoras sin modificar su arquitectura principal.
